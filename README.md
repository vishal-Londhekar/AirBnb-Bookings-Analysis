# Airbnb Bookings Analysis — Exploratory Data Analysis

A Python exploratory analysis of Airbnb listings in New York City, focused on pricing, neighbourhoods, room types, availability, reviews, and host activity.

## Project objective

The notebook examines listing-level patterns and converts them into descriptive insights for hosts, marketplace analysts, and hospitality teams.

## Dataset

**Airbnb NYC 2019.csv** contains the New York City Airbnb listing data used by the notebook. Confirm the original source and licence before redistribution.

## Files

- **AirBnb_Bookings_Analysis_Exploratory_Data_Analysis (1).ipynb** — analysis notebook
- **Airbnb NYC 2019.csv** — dataset
- **README.md** — project documentation

## Tools

Python, pandas, NumPy, Matplotlib, Seaborn, and exploratory data analysis techniques.

## How to run

1. Install Python and Jupyter Notebook.
2. Install pandas, NumPy, Matplotlib, and Seaborn.
3. Keep **Airbnb NYC 2019.csv** in the same directory as the notebook.
4. Open **AirBnb_Bookings_Analysis_Exploratory_Data_Analysis (1).ipynb**.
5. Run the notebook sequentially. If a data-path cell is present, update it to the local path of the CSV file.

## Analysis areas

- Price and room-type distributions
- Neighbourhood and geographic patterns
- Review and availability behaviour
- Host activity and listing concentration
- Outlier and missing-value inspection

## Limitations

- The analysis is descriptive and does not establish causal relationships.
- The dataset is a historical snapshot and does not represent current Airbnb inventory.
- Add the dataset source, collection date, and licence details for stronger reproducibility.
